# Trigger cases after the 0.10.0 rename, 2026-10-27

Model: three fresh Claude Haiku runs (the Agent tool's `haiku` setting; the exact version was not shown to the session). Same vendor family as the author, so these runs are not independent. Each saw only the 57 skill names with their descriptions from depot `main` at `95bafe6` (0.10.0, with `review-usability` and `settle-decisions`) and 20 shuffled requests, with no tools and no file access, and was asked for one skill per request or none. Raw answers: [run 1](2026-10-27-naming-cases/answers-run1.txt), [run 2](2026-10-27-naming-cases/answers-run2.txt), [run 3](2026-10-27-naming-cases/answers-run3.txt). The first column below is the request number in those files.

Why: 0.10.0 renamed `run-heuristic-evaluation` to `review-usability` and `decide-plan` to `settle-decisions`. Only T14 in [behavioral-cases.md](../behavioral-cases.md) names a renamed skill, so this run adds the other existing requests that expect either skill, plus their closest neighbors: `refine-issue`, `plan-usability-test`, and `review-accessibility`. Every request is copied unedited from the existing tables. Expected answers are the recorded ones, mapped through the [0.10.0 rename table](../../CHANGELOG.md#0100).
