**Goal:** find out why your landing page feels cluttered by critiquing its spacing and type hierarchy.

**Start with:** S `visual-design-critique`. You already know the symptoms (clutter, spacing, type hierarchy), and this skill covers hierarchy, spacing and type critique.

**Then, if needed:** A `design-reviewer`, if you want a broader review afterward that also covers usability and accessibility.

**What to bring:** a screenshot or live link of the landing page (desktop and mobile if you have both). Add one line on what the page should get visitors to do and any brand or type constraints you need to keep.

**Models** (no model table is available, so these are roles rather than model names):
- Critique: a mid-tier model, `medium` effort.
- Review of the findings or the follow-up design review: the strongest reasoning model available, `high` effort. Use a different model family from the critique so the review is independent.
