**Goal:** Get structured feedback on the spacing and type hierarchy of your cluttered landing page.

**Start with:** `review-visual-design` (skill). It assesses visual hierarchy, spacing, typography, alignment, and consistency. It also separates real requirements from conventions and personal preference, so you'll know which fixes matter.

**Alternates (optional):**
- `design-reviewer` (agent), if you'd rather have one reviewer own the whole critique, including usability and accessibility.
- `specify-responsive-layout`, if the clutter turns out to come from how the layout behaves at different sizes.

**What to give it:** a screenshot or the design file of the landing page, and who it's for and what the page should get them to do. Naming the one or two sections that feel worst is optional but speeds things up.

**Models:** I don't have a model table, so I'm naming roles instead of specific models. Use a mid-tier model at `medium` effort for the critique. Use the strongest available reasoning model at `high` effort only if you add a separate final review. If you share a model table, I can name specific models.

**Gap:** none. Keep in mind that this skill critiques an existing design. It won't redesign the page for you, because the library doesn't create visual design directly.
